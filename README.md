# МЭШ — автозадание ДЗ по дню

Расширение для Chrome, автоматизирующее рутинную задачу в МЭШ (school.mos.ru): проставление домашнего задания «Не задано.» для уроков выбранного дня, у которых оно ещё не выставлено.

## Установка

1. Скачайте или склонируйте этот репозиторий.
2. Откройте `chrome://extensions`.
3. Включите «Режим разработчика» (в правом верхнем углу).
4. Нажмите «Загрузить распакованное расширение» и выберите папку репозитория.

## Использование

1. Откройте страницу расписания уроков в личном кабинете учителя МЭШ (`school.mos.ru/teacher/account/schedule`).
2. Нажмите на иконку расширения.
3. Выберите нужный день текущей недели.
4. Расширение пройдётся по урокам этого дня и создаст задание «Не задано.» для тех, у которых домашнее задание ещё отсутствует.

## Файлы

- `manifest.json` — манифест расширения (Manifest V3).
- `content.js` — основная логика: поиск уроков без ДЗ и создание задания.
- `inject.js` — скрипт, внедряемый в контекст страницы (`world: MAIN`).
- `background.js` — service worker.
- `popup.html` / `popup.js` — интерфейс всплывающего окна расширения.

## Важно

Дата проверки задания при создании подставляется автоматически самим МЭШ (обычно — следующее занятие этого класса), так как сайт не позволяет выбрать дату проверки раньше «сегодня + 2 дня» ни при каких условиях. Это ограничение самого сайта, а не расширения.
